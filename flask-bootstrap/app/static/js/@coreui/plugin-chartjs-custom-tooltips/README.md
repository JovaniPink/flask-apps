# CoreUI Chart.js custom tooltips

This directory retains the unbuilt browser source from
`@coreui/plugin-chartjs-custom-tooltips` 0.0.1. Its file header records the 2018
CoreUI copyright and MIT license.

The historical package manifest and Babel/ESLint/Uglify development graph are
intentionally not vendored. This repository does not build this directory. If
the browser source is ever activated or replaced, review its Chart.js 2 API
compatibility and preserve its license notice.
